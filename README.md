# Ответы — ДЗ1 по веб-разработке

Простая статическая вёрстка на Bootstrap, по присланному примеру.

## Как открыть

Открой `public/index.html` в браузере. Всё необходимое лежит в проекте: интернет и установка зависимостей не нужны.

При желании можно запустить из корня проекта:

```bash
python3 -m http.server 8000 --directory public
```

После этого открыть http://localhost:8000/.

## Страницы

- `base.html` — общий каркас на примере главной.
- `index.html` — новые вопросы, по два вопроса на страницу.
- `hot.html` — популярные вопросы.
- `tag.html` — вопросы по тегу.
- `question.html` — вопрос, ответы, правильный ответ и форма ответа.
- `ask.html` — добавление вопроса.
- `login.html` — вход.
- `signup.html` — регистрация.
- `profile.html` — настройки профиля.

## Что где менять

- Содержание страницы — в соответствующем HTML-файле.
- Расположение блоков и небольшие поправки оформления — `public/static/css/base.css`.
- Демонстрационные действия кнопок — `public/static/js/app.js`.
- Изображения — `public/static/img/`.

Сетка, кнопки, поля, карточки, бейджи и пагинация используют обычные классы Bootstrap: `row`, `col-lg-8`, `btn btn-primary`, `form-control`, `card`, `badge`, `pagination`. Bootstrap подключается локально. Его файлы менять не нужно.

Собственные классы нужны только для расположения: например, `author-column` задаёт ширину блока автора, а `question-layout` ставит автора и текст рядом. Декоративных тем, дополнительных библиотек и сборщика нет.

## Что работает в демонстрации

Голосование, переключение страниц, выбор правильного ответа, поиск по готовым карточкам, фильтр тегов, проверка полей и предпросмотр выбранного аватара. После перезагрузки изменения сбрасываются. Формы не сохраняют данные и не выполняют настоящую регистрацию или вход.

Все заголовки вопросов ведут на один макет `question.html`. Ссылки участников ведут на один макет профиля. На страницах входа и регистрации заранее показаны примеры ошибок для проверки вёрстки. Три состояния голосования представлены в карточках на разных страницах пагинации. В боковой колонке — три примера тегов и три пользователя; полные списки появятся с бэкендом.

## Дальше — Django

Общий header, sidebar и footer можно вынести в `base.html`, содержимое страниц — в `{% block content %}`, а карточки выводить циклом. У полей уже есть `name`. При подключении сервера назначь формам реальные `action`, добавь CSRF-токен и замени демонстрационный JavaScript серверной логикой.

В ДЗ1 общий каркас скопирован между страницами: это разрешено заданием.
