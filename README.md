# Ответы — ДЗ 2

Сайт вопросов и ответов на Django. Вёрстка и локальные файлы Bootstrap взяты из ДЗ 1. Вопросы, ответы и профиль заполнены примерами. Формы и голосование можно попробовать в браузере, изменения после перезагрузки сбрасываются.

## Запуск на компьютере

Нужен Python 3.12. Команды запускаются из корня репозитория.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py runserver
```

На Windows для активации в PowerShell используй `.\.venv\Scripts\Activate.ps1`. Сайт откроется по адресу [http://localhost:8000/](http://localhost:8000/). Для ДЗ 2 миграции запускать не нужно.

Если нужно поменять настройки запуска, скопируй `.env.example` в `.env` и измени значения в копии.

## Запуск через Docker Compose

```bash
docker compose up --build
```

Сайт доступен по тому же адресу. Папка с кодом подключается к контейнеру, а для `media/` выделен отдельный том. Для остановки нажми Ctrl+C или выполни `docker compose down`.

## Страницы

| Адрес | Что открывается |
| --- | --- |
| `/` | Новые вопросы и поиск |
| `/hot/` | Вопросы по рейтингу |
| `/tag/bootstrap/` | Вопросы с тегом `bootstrap` |
| `/question/35/` | Вопрос с 32 ответами |
| `/ask/` | Форма нового вопроса |
| `/login/` | Форма входа |
| `/signup/` | Форма регистрации |
| `/profile/` | Настройки демонстрационного профиля |

Чтобы проверить пагинацию, добавь `?page=2` к списку вопросов, тегу `bootstrap` или вопросу №35. На странице выводится до 20 вопросов или до 30 ответов. Если номер не указан, некорректен или выходит за границы, откроется первая страница.

## Где что лежит

- `application/` — настройки Django и подключение маршрутов приложений.
- `core/` — страницы входа, регистрации и профиля, общий шаблон `base.html` и локальная статика.
- `questions/` — страницы вопросов, тестовые данные в `mock_data.py` и общая функция `paginate` в `pagination.py`.

Например, для `/question/35/?page=2` Django находит маршрут вопроса, передаёт ID во view, а `paginate` выбирает вторую страницу ответов. Шаблон получает вопрос и эти ответы. Адреса страниц собираются тегом `url`, пути к стилям, скриптам и картинкам — тегом `static`.
